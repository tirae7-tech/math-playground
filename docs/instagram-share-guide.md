# 인스타그램 공유 가이드

배포 URL이 정해지면 아래 주소를 실제 URL로 바꿔 사용하세요.

```txt
https://실제배포주소
```

## 첫 게시글 문구

아이와 함께 하루 10문제만 가볍게 풀어보는 **사칙연산 놀이터**를 공유합니다.

설치나 로그인 없이 링크만 누르면 바로 시작할 수 있고, 이름이나 학교명을 입력하지 않아도 됩니다. 덧셈, 뺄셈, 곱셈, 나눗셈을 난이도별로 골라 연습할 수 있어요.

처음 써본다면 아래 링크를 추천해요.

```txt
https://실제배포주소/?mode=mix&level=easy
```

## QR코드 문구

QR코드를 찍고 사칙연산 10문제만 풀어보세요.

설치 없이, 로그인 없이 바로 시작할 수 있어요.

## 댓글 고정용 문구

```txt
바로 해보기: https://실제배포주소/?mode=mix&level=easy

설치 없음, 로그인 없음, 개인정보 입력 없음.
아이들이 부담 없이 10문제만 가볍게 풀어볼 수 있어요.
```
